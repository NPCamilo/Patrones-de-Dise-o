# Patrones de Diseño — Recursos

## Knowledge

- [Libro: _Design Patterns: Elements of Reusable Object-Oriented Software_ (Gang of Four)](https://www.amazon.com/Design-Patterns-Elements-Reusable-Object-Oriented/dp/0201633612)
  Fuente primaria de los 23 patrones, incluido State. Úsalo cuando necesites la definición canónica y las consecuencias de cada patrón.
- [Artículo: State pattern — Refactoring Guru (español)](https://refactoring.guru/es/design-patterns/state)
  Explicación clara y visual del patrón State con participantes, estructura y ejemplo de código. Úsalo para repasar antes de una exposición.
- [Libro: _Head First Design Patterns_ por Eric Freeman y Elisabeth Robson](https://www.oreilly.com/library/view/head-first-design/0596007124/)
  Enfoque amigable y visual para entender cuándo usar cada patrón. Úsalo si el libro de GoF te resulta demasiado denso.

## Wisdom (Comunidades)

- [r/designpatterns](https://www.reddit.com/r/designpatterns/)
  Subreddit dedicado a patrones de diseño. Úsalo para pedir crítica de tu implementación de State.
- [Stack Overflow — etiqueta `design-patterns`](https://stackoverflow.com/questions/tagged/design-patterns)
  Úsalo para dudas puntuales sobre cómo aplicar State en un lenguaje concreto.

## Gaps

- No se identificó un recurso en español que combine State con Strategy, Observer y Command en un solo ejemplo integrado.
