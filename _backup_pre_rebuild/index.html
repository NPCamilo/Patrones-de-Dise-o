2. Qué es State

State permite que un objeto cambie su comportamiento cuando su estado interno cambia, delegando en objetos de estado separados.

Parece que el objeto cambió de clase, pero en realidad solo cambia a qué objeto de estado delega.

3. State vs Strategy

AspectoStateStrategy
¿Quién decide?El objeto mismo, por su estado internoEl cliente, desde afuera
¿Cambia en ejecución?Sí, el objeto transita entre estadosGeneralmente no, el cliente lo fija

Lección 3: Implementación mínima en Python

Código copiable, probado y listo para ejecutar

1. Código completo

Guárdalo como estado_pedido.py y ejecútalo con python estado_pedido.py.

from __future__ import annotations
from abc import ABC, abstractmethod

class EstadoPedido(ABC):
    @abstractmethod
    def pagar(self, pedido: "Pedido") -> None: ...
    @abstractmethod
    def enviar(self, pedido: "Pedido") -> None: ...
    @abstractmethod
    def cancelar(self, pedido: "Pedido") -> None: ...

class Pendiente(EstadoPedido):
    def pagar(self, pedido): pedido.estado = Pagado(); print("Pago aceptado")
    def enviar(self, pedido): print("No se puede enviar aún")
    def cancelar(self, pedido): pedido.estado = Cancelado(); print("Cancelado")

class Pagado(EstadoPedido):
    def pagar(self, pedido): print("Ya está pagado")
    def enviar(self, pedido): pedido.estado = Enviado(); print("Pedido enviado")
    def cancelar(self, pedido): print("No se puede cancelar")

class Enviado(EstadoPedido):
    def pagar(self, pedido): print("Ya se envió")
    def enviar(self, pedido): print("Ya se envió")
    def cancelar(self, pedido): print("No se puede cancelar")

class Cancelado(EstadoPedido):
    def pagar(self, pedido): print("Está cancelado")
    def enviar(self, pedido): print("Está cancelado")
    def cancelar(self, pedido): print("Ya está cancelado")

class Pedido:
    def __init__(self): self.estado: EstadoPedido = Pendiente()
    def pagar(self): self.estado.pagar(self)
    def enviar(self): self.estado.enviar(self)
    def cancelar(self): self.estado.cancelar(self)

if __name__ == "__main__":
    p = Pedido()
    p.pagar()   # -> Pagado
    p.enviar()  # -> Enviado
    p.pagar()   # -> Bloqueado

Lección 5: State con Observer y Command

Notificar cambios de estado y hacer transiciones deshacibles

1. Observer: avisar al cambiar de estado

El Context notifica a observadores cada vez que transita a un nuevo estado.

class ObservadorPedido(ABC):
    @abstractmethod
    def actualizar(self, pedido, anterior, nuevo): ...

class NotificadorEmail(ObservadorPedido):
    def actualizar(self, pedido, anterior, nuevo):
        print(f"[Email] {pedido.id}: {anterior} -> {nuevo}")

class Pedido:
    def __init__(self, id):
        self.id = id
        self.estado = Pendiente()
        self._observadores = []
    def agregar_observador(self, obs):
        self._observadores.append(obs)
    def cambiar_estado(self, nuevo):
        ant = type(self.estado).__name__
        self.estado = nuevo
        for obs in self._observadores:
            obs.actualizar(self, ant, type(nuevo).__name__)

2. Command: transiciones deshacibles

Cada cambio de estado se encapsula como un objeto comando reversible.

class ComandoTransicion(ABC):
    @abstractmethod
    def ejecutar(self): ...
    @abstractmethod
    def deshacer(self): ...

class ComandoPagar(ComandoTransicion):
    def __init__(self, pedido, estado_anterior):
        self.pedido = pedido
        self.estado_anterior = estado_anterior
    def ejecutar(self):
        self.pedido.pagar()
    def deshacer(self):
        mapa = {"Pendiente": Pendiente(), "Pagado": Pagado(), "Enviado": Enviado()}
        self.pedido.estado = mapa[self.estado_anterior]

Glosario rápido

TérminoSignificado
StateObjeto que permite cambiar el comportamiento según el estado interno.
ContextObjeto principal que delega en el estado actual.
ConcreteStateImplementación concreta de un estado específico.
StrategyEl cliente elige el algoritmo; distinto de State.
ObserverNotifica a varios objetos cuando el estado de otro cambia.
CommandEncapsula una solicitud como un objeto para desacoplar remitente y receptor.
