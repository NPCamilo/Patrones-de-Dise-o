Lección 3: Implementación mínima de State en Python

Tu primera máquina de estados

Un Pedido que pasa de Pendiente a Pagado y luego a Enviado, con transiciones inválidas bloqueadas automáticamente.

Python 3 · Estándar · 20 min

¿Por qué esta lección ahora?

Ya conoces la anatomía de State. Ahora vas a escribir el código completo, ejecutarlo tú mismo y ver cómo el comportamiento cambia según el estado sin un solo if estado == ....

1. El problema que resuelve State

✘ Antes (sin State)
if estado == "pendiente":
    if acción == "pagar":
        estado = "pagado"
    elif acción == "enviar":
        print("No se puede enviar")
elif estado == "pagado":
    if acción == "enviar":
        estado = "enviado"
    ...
✔ Después (con State)

Cada estado es una clase. El Context solo delega. Agregar un nuevo estado no toca el Context.

2. Código completo (copia y ejecuta)

Guárdalo como estado_pedido.py y ejecútalo con python estado_pedido.py.

from __future__ import annotations
from abc import ABC, abstractmethod


# ============================================================================
# STATE — Interfaz común de todos los estados
# ============================================================================
class EstadoPedido(ABC):
    """Cada estado concreto implementa estos tres métodos."""

    @abstractmethod
    def pagar(self, pedido: "Pedido") -> None:
        ...

    @abstractmethod
    def enviar(self, pedido: "Pedido") -> None:
        ...

    @abstractmethod
    def cancelar(self, pedido: "Pedido") -> None:
        ...


# ============================================================================
# CONCRETESTATE — Una clase por estado real
# ============================================================================
class Pendiente(EstadoPedido):
    """El pedido aún no se ha pagado."""

    def pagar(self, pedido: "Pedido") -> None:
        pedido.estado = Pagado()
        print("Pago aceptado. El pedido ahora está pagado.")

    def enviar(self, pedido: "Pedido") -> None:
        print("No se puede enviar: el pedido aún no se ha pagado.")

    def cancelar(self, pedido: "Pedido") -> None:
        pedido.estado = Cancelado()
        print("Pedido cancelado antes de pagar.")


class Pagado(EstadoPedido):
    """El pedido se pagó pero aún no se envió."""

    def pagar(self, pedido: "Pedido") -> None:
        print("El pedido ya está pagado. No se puede pagar dos veces.")

    def enviar(self, pedido: "Pedido") -> None:
        pedido.estado = Enviado()
        print("Pedido enviado al cliente.")

    def cancelar(self, pedido: "Pedido") -> None:
        print("No se puede cancelar: el pedido ya está pagado o enviado.")


class Enviado(EstadoPedido):
    """El pedido ya fue despachado."""

    def pagar(self, pedido: "Pedido") -> None:
        print("Ya se envió el pedido. No se puede pagar.")

    def enviar(self, pedido: "Pedido") -> None:
        print("El pedido ya fue enviado previamente.")

    def cancelar(self, pedido: "Pedido") -> None:
        print("No se puede cancelar un pedido ya enviado.")


class Cancelado(EstadoPedido):
    """Estado terminal: el pedido se canceló."""

    def pagar(self, pedido: "Pedido") -> None:
        print("El pedido está cancelado. No se puede pagar.")

    def enviar(self, pedido: "Pedido") -> None:
        print("El pedido está cancelado. No se puede enviar.")

    def cancelar(self, pedido: "Pedido") -> None:
        print("El pedido ya está cancelado.")


# ============================================================================
# CONTEXT — El objeto principal que delega en su estado actual
# ============================================================================
class Pedido:
    """Mantiene una referencia al estado actual y delega cada operación."""

    def __init__(self) -> None:
        self.estado: EstadoPedido = Pendiente()

    def pagar(self) -> None:
        self.estado.pagar(self)

    def enviar(self) -> None:
        self.estado.enviar(self)

    def cancelar(self) -> None:
        self.estado.cancelar(self)


# ============================================================================
# PRUEBA — Ejecuta este bloque para ver el patrón en acción
# ============================================================================
if __name__ == "__main__":
    p = Pedido()

    print("=== Escenario feliz ===")
    p.pagar()   # Pendiente → Pagado
    p.enviar()  # Pagado → Enviado

    print("\n=== Transiciones inválidas (bloqueadas) ===")
    p.pagar()   # Enviado → No se puede pagar
    p.cancelar()  # Enviado → No se puede cancelar

3. ¿Qué hace cada bloque?

BloqueRol en el patrón
EstadoPedido (ABC) Es el State. Declara el contrato que todos los estados deben cumplir.
Pendiente, Pagado, Enviado, Cancelado Son los ConcreteState. Cada uno implementa su propio comportamiento y decide cuándo cambiar pedido.estado.
Pedido Es el Context. No tiene condicionales if estado == ...; solo llama self.estado.<método>(self).
if __name__ == "__main__": Prueba rápida: recorre el camino feliz y luego intenta transiciones inválidas para ver que están bloqueadas.
